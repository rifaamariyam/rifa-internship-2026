Mushroom Yield Prediction Using Machine Learning and Environmental Sensor Data

Technical Report

Author: Rifa Mariyam


---

Abstract

This project presents the design and implementation of a machine learning pipeline for predicting oyster mushroom yield using environmental sensor measurements collected from a controlled polyhouse. The study integrates data ingestion, preprocessing, exploratory data analysis, feature engineering, supervised learning, model evaluation, hyperparameter optimization, deployment, and monitoring into a reproducible workflow. Temperature, relative humidity, and carbon dioxide concentration were used as predictive variables. Multiple regression models were evaluated using chronological train-test splitting and TimeSeriesSplit cross-validation to avoid temporal data leakage. The final system was deployed as an interactive Streamlit application capable of real-time yield prediction.
